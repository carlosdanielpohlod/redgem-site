# RedGem 3D Engine: website

The landing page of the RedGem 3D Engine, served with GitHub Pages: `index.html`, the files in
`assets/`, and the user manual in `manual/` (built from the engine's `docs/` with MkDocs).

Fonts: Inter and JetBrains Mono (SIL Open Font License, see `assets/*-LICENSE.txt`).
